## Persistencia Definitiva dos Dados (SC/OC)

Por padrao, o sistema roda com persistencia em memoria. Para garantir que tudo fique salvo mesmo apos reinicio/deploy, habilite Supabase:

1. Crie um projeto no Supabase.
2. No SQL Editor do Supabase, aplique as migrations da pasta `supabase/migrations`, incluindo:
	- `004_procurement_persistence_core.sql`
3. Configure variaveis de ambiente:
	- `PROCUREMENT_PERSISTENCE_DRIVER=supabase`
	- `SUPABASE_URL=<url-do-projeto>`
	- `SUPABASE_SERVICE_ROLE_KEY=<service-role-key>`
4. Em producao (Vercel), adicione as mesmas variaveis em Project Settings > Environment Variables.
5. Redeploy da aplicacao.

Como validar:

- Acesse `GET /api/procurement/state` e confirme `persistence.driver = supabase`.
- Crie SC/OC, recarregue a pagina e reinicie o servidor; os dados devem permanecer.
