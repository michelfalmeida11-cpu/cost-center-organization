# Fiori Visual Base (sem Dashboard/CRUD/páginas)

Este módulo contém:
- Layout visual (Sidebar/Header/Footer) inspirado em SAP Fiori / Oracle Fusion
- Design system base com componentes reutilizáveis
- Estilização via Tailwind + tokens inline para manter a paleta solicitada

Observações:
- Não contém páginas Next.js.
- Não contém gráficos nem CRUD.
